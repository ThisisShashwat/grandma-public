Grandma baked nothing here without help. Here is the pantry list.

## Who made this

The program is run by Shashwat, with [Hack Club](https://hackclub.com/), the nonprofit behind programs like this one. How the code and the pictures were made is on the [AI disclosure](/guides/ai-disclosure/) page.

## Text from other places

None of the text in these guides is adapted from other Hack Club repositories. It was all written for this program. If that ever changes, the adapted page will say where the text came from and under which license, at the bottom of that page.

## Libraries

**On the server**

- [Django](https://www.djangoproject.com/), the web framework
- [Jinja2](https://jinja.palletsprojects.com/), the page templates
- [django-environ](https://django-environ.readthedocs.io/), settings from the environment
- [python-frontmatter](https://github.com/eyeseast/python-frontmatter), reads the top of each guide
- [markdown-it-py](https://github.com/executablebooks/markdown-it-py) and [mdit-py-plugins](https://github.com/executablebooks/mdit-py-plugins), turn the Markdown of these guides into pages
- [Pygments](https://pygments.org/), colors the code samples
- [nh3](https://github.com/messense/nh3), cleans the pages so nothing sneaky gets through

**In your browser**

- [GSAP](https://gsap.com/), the motion
- [Rough Notation](https://roughnotation.com/), the hand-drawn scribbles
- [canvas-confetti](https://github.com/catdad/canvas-confetti), the confetti
- [Google Fonts](https://fonts.google.com/): Gochi Hand for headings and Comic Neue for text

Each of these keeps its own license. Follow the links.
